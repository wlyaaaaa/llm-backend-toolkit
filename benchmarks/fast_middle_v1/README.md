# fast_middle_v1

这是 2026-07-24 高速中档智能体验收使用的公共合成任务说明。原始工作区只包含四类合成材料：

1. PersonalOS 风格对话清洗：用户纠正、未知时间、外部未核验来源、模型风格和跨样例隔离；
2. 跨文件路由诊断：先失败的 preflight、后续 diagnostic、名称规范化与静默默认回退；
3. 非代码证据归并：顶级/Spark/本地三层角色、云端许可、额度未知与可见回退；
4. 现实因果短题：50 米外洗车应把车开到洗车点。

完整原始回执保留在验收工作区而不提交 Git，因为其中包含本机绝对路径、线程 ID 和运行时版本。公共结论、任务尺度、墙钟、分数、硬错误和边界见 [Spark 高速中档智能体验收报告](../../docs/fast-middle-agent.md)。

本目录不是代码榜单。复验必须同时运行 `fast-middle-agent` 和 `local-default`，禁止加入顶级模型分数，禁止调用 qwen3.7-plus API，禁止读取真人材料，且必须保留独立结构/语义 verifier。默认 Qwen 路由不得因复验而改变。
